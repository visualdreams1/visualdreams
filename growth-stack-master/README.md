# Growth Stack Master Agent

The business brain for Growth Stack Global.

## Purpose
Operate Growth Stack Global as an AI-first service business, with Growth Stack itself as Customer #001.

## Repository structure
- `MASTER_AGENT.md` — core constitution and operating rules
- `MEMORY_SCHEMA.md` — portable business-memory design
- `PRODUCT_CATALOG.md` — initial service catalog
- `7_DAY_MISSION.md` — first revenue mission

## Ownership principle
The project is designed around owner-controlled business assets: instructions, memory structures, workflows, documentation and source code. The underlying AI model is replaceable.

## Current state
Foundation created. The next build phase is the execution layer: structured data, agent/tool interfaces, approval gates, monitoring, and a minimal runnable operator.

## Non-negotiable
The agent optimizes for real value and revenue, not activity or hype.
